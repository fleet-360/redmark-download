התקנת התוסף Pro Algorithm

תוסף ל-Revit בגרסאות 2023 עד 2027. ההתקנה היא למשתמש הנוכחי ולא דורשת הרשאות מנהל. מתקינים פעם אחת, ומשם התוסף מתעדכן לבד.

הורדת קובץ ההתקנה גרסה 1.0.2 · 8MB · ProAlgorithm-Setup.exe

שלבי ההתקנה

  1. מורידים את קובץ ההתקנה לוחצים על הכפתור "הורדת קובץ ההתקנה" שלמעלה. הקובץ נשמר בתיקיית ההורדות.
  2. מריצים את הקובץ לוחצים פעמיים על ProAlgorithm-Setup.exe.

    אם מופיע המסך "Windows הגן על המחשב שלך": לוחצים על מידע נוסף ואז על הפעל בכל זאת. האזהרה מופיעה כי הקובץ לא חתום דיגיטלית.

  3. מאשרים את ההתקנה בחלון ההתקנה לוחצים התקן, ובסיום סיים. אין מה לבחור: ההתקנה מזהה לבד את גרסאות Revit שמותקנות במחשב, ומוסיפה את התוסף לכל אחת מהן.
  4. פותחים את Revit מחדש אם Revit היה פתוח בזמן ההתקנה, סוגרים אותו ופותחים שוב. התוסף נטען רק בפתיחה של Revit.

    אם Revit מציג את החלון Security - Unsigned Add-In: לוחצים Always Load. כך Revit טוען את התוסף בלי לשאול שוב.

  5. בודקים שהתוסף נטען ב-Revit פותחים את הלשונית Pro Algorithm - Surface. בפאנל כמויות ורשימות מופיעים הכפתורים רשימת חלונות ו-תוצאות אחרונות.

עדכונים

אין צורך להוריד שוב כשיוצאת גרסה חדשה. בכל פתיחה של Revit התוסף בודק ברקע אם יש גרסה חדשה ומוריד אותה. כשהעדכון מוכן מופיעה הודעה, והגרסה החדשה פעילה מהפתיחה הבאה של Revit.

הבדיקה צריכה חיבור לאינטרנט. כדי לראות איזו גרסה מותקנת, מעבירים את העכבר מעל הכפתור רשימת חלונות, או מחפשים בהגדרות Windows תחת "אפליקציות".

אם משהו לא עובד

הלשונית או הכפתורים לא מופיעים ב-Revit
סוגרים את Revit לגמרי ופותחים שוב. אם עדיין לא מופיעים, מריצים שוב את קובץ ההתקנה, ובפתיחת Revit בוחרים Always Load אם החלון מופיע.
ההתקנה מודיעה שלא נמצאה התקנה של Revit
ההתקנה מחפשת את Revit 2023 עד 2027 בתיקייה C:\Program Files\Autodesk. אם Revit מותקן במקום אחר או בגרסה אחרת, פנו אלינו.
התוסף לא התעדכן
עדכון נכנס לפעולה רק בפתיחה שאחרי ההורדה, ורק כשיש חיבור לאינטרנט. כדי לעדכן מיד, מורידים ומריצים שוב את קובץ ההתקנה מהעמוד הזה: הוא תמיד בגרסה האחרונה ומתקין מעל הגרסה הקיימת.
אפשר להתקין כש-Revit פתוח?
כן. ההתקנה לא נוגעת בקבצים ש-Revit משתמש בהם, והגרסה החדשה נטענת בפתיחה הבאה.
איך מסירים את התוסף?
בהגדרות Windows פותחים "אפליקציות", בוחרים ב"פרו אלגוריתם - כמויות ורשימות" ולוחצים "הסר התקנה".
